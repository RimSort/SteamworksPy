# SteamworksPy
This project is a fork of philippj's SteamworksPy which itself started as a fork of Easimer's SteamworksForPython.

## Building

Building requires the Steamworks SDK.

After extracting the SDK to the root of this repository, use the universal make file found in the root of the project to build the required binaries.

## Usage
Please check the examples in the "examples" directory for a basic understanding of the module. For further reference you can go through the interface implementations itself or use the official Steamworks documentation (https://partner.steamgames.com/doc/api)
